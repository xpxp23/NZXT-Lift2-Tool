# NZXT Lift 2 Ergo 原生电竞独立驱动与控制面板 (`lift2.exe`)

专为 **NZXT Lift 2 Ergo**（及 Lift 2 全系列）打造的纯原生超轻量 Rust 驱动与图形控制面板。彻底摆脱臃肿且经常卡死的官方 NZXT CAM（~500 MB 内存、5个子进程、频繁占用 CPU）。

- 🪶 **极致极低内存架构**：彻底剥离 OpenGL / eframe 显卡管线与 38.5MB 字体堆内存，采用 Windows 原生 GDI 双缓冲无闪烁自绘。**前台开窗仅 ~5.1 MB 内存，托盘后台驻留仅 ~4.4 MB，单文件仅 0.88 MB**！纯绿色免安装，无任何外部依赖。
- 🎨 **双风格一键切换**：右上角胶囊快速切换【🌙 电竞紫曜 Minimal Obsidian】与【🪟 Win11 Fluent Dark】，实时保存至配置文件。
- 🎮 **现代原生图形界面 (GUI)**：无黑框控制台弹出（`#![windows_subsystem = "windows"]`），窗口 800x570 舒适比例，文字与控件零裁切。
- ⚡ **超高回报率调节 (Polling Rate)**：胶囊式下拉菜单，支持 125Hz、250Hz、500Hz、1000Hz、2000Hz、4000Hz、**8000Hz (0.125ms 极限低延迟)** 一键切换。
- 📏 **静默高度调节 (LOD)**：胶囊式下拉菜单，支持 **1mm (Low / 电竞超低静默)** 与 **2mm (High / 厚脚贴兼容)** 硬件级切换。
- 🎯 **5档板载 DPI 自定义**：支持 50 ~ 26,000 DPI（50 步进），可视化平滑滑条、[-50]/[+50] 微调、常用档位速选（400/800/1600/2400/3200/6400）与三大电竞模板（FPS 经典、MOBA 微操、4K 高分）。
- 👆 **全区域 DPI 按钮**：整块档位按钮卡片任意位置均可直接点击切换，彻底告别“只能点文字”的问题。
- 💾 **直接写入板载 Flash**：所有 DPI、回报率、LOD 设置直接烧录在鼠标板载芯片中，关机断电或更换电脑永久保持。
- ⌨️ **自定义开机卡死急救快捷键 (默认 `Ctrl + Shift + F12`)**：**当鼠标开机失灵无法点击时，无需插拔 USB，直接在键盘上按下快捷键即可秒级复位！** 支持在 UI 中一键选用预设或配置文件自定义。
- 🚀 **内置开机自启开关**：UI 界面直接提供“开机自动在后台运行”勾选框，基于 Windows 注册表持久化自启，无需手动创建快捷方式。
- 🖥️ **Win32 原生悬浮 OSD**：点击机身物理 DPI 键或切换设置时，屏幕即时弹出半透明 HUD 提示框（1.2 秒自动淡出）。
- 📥 **智能托盘生命周期**：点击窗口右上角“X”或“最小化到托盘”，**彻底销毁 UI 线程与图形上下文并释放工作集内存**，后台持续低功耗守护 OSD、DPI 按键监听与全局急救热键。

## ⚡ 彻底根治“开机左键卡死/无法左右键点击”

### 为什么开机会出现这个现象？
NZXT Lift 2 采用了超轻量 **光微动开关**（Optical Switches）。其原理是通过红外光通断判定按压状态（遮光 = 按下，透光 = 抬起）。
在电脑冷启动或 Windows 快速启动（Fast Startup）唤醒时：
1. 主板 5V USB 供电还在升压爬升阶段，鼠标 MCU 已提前上电执行光微动的初始基准电压校准。
2. 此时红外发射二极管尚未达到恒定导通电流，光敏接收管测得 0V（暗电平），MCU 将初始状态误判并锁死在**逻辑“按下”**。
3. 此时虽然光标能够移动，但**左键被永久识别为按住状态，导致所有左右键单击均无法响应**。

### 本驱动提供的四重根治方案：
1. **全局键盘急救快捷键 (`Ctrl + Shift + F12`)**：
   考虑到鼠标卡死时已经无法用鼠标去点击任何按钮，驱动注册了操作系统底层全局热键。只要在键盘上同时按下 `Ctrl + Shift + F12`，驱动立刻调用 Windows Hub 原生接口下发 `IOCTL_USB_CYCLE_PORT`，命令 USB Hub 端口物理级切断供电并重新通电，1.5 秒内完成传感器重新自检并恢复正常！
2. **状态感知防误触**：
   彻底杜绝盲目发送右键事件，改用 `GetAsyncKeyState` 物理按键状态感知，仅在检测到异常虚假卡键时才释放，消除双击启动误触右键菜单的问题。
3. **UI 一键急救按钮**：
   在控制面板界面中设有醒目的“立即重置 USB 端口”按钮。
4. **注册表永久禁止 USB 节电休眠**：
   一键写入 Windows 注册表，将该鼠标的 `EnhancedPowerManagementEnabled` 与 `SelectiveSuspendEnabled` 永久置 0，杜绝系统因节能挂起导致的供电欠压。

## 🚀 启动与使用指南

### 1. 正常启动图形界面
直接双击运行 `lift2.exe`：
- **无黑框控制台**，直接呈现原生控制面板。
- 可调节：5 档 DPI、7 种回报率（125Hz ~ 8000Hz）、2 档 LOD（1mm / 2mm）。
- 右上角可一键切换【电竞紫曜】与【Win11 Fluent】两套风格。
- 勾选“开机自动在后台运行”即可无感开机常驻。
- 点击右上角 `X` 或“最小化到托盘”，立即销毁图形管线进入极低内存挂机模式。

### 2. 系统托盘右键菜单
托盘图标显示当前实时 DPI 与档位，单击或双击托盘图标恢复控制面板，右键可呼出快捷菜单：
- 🎮 **Open Control Panel**：重新打开控制面板。
- **Stage 1 ~ Stage 5**：直接切换生效档位。
- ⚡ **Reset Mouse USB [快捷键]**：触发底层硬件断电重连。
- 🛠️ **Disable USB Power Sleep**：应用注册表防休眠补丁。
- 📂 **Open Config File**：用记事本打开 `config.toml`。
- **Exit**：彻底退出驱动。

### 3. 高级命令行模式（供脚本调用）
`lift2.exe` 依然保留完整的静默 CLI 接口：
```bash
# 查看鼠标当前状态（版本、回报率、LOD、板载各档DPI）
lift2.exe status

# 切换当前生效档位（1 至 5）
lift2.exe switch 2

# 修改某档 DPI 并写入板载 Flash（例如将第 1 档设为 800）
lift2.exe set-dpi 1 800

# 修改回报率（支持 125, 250, 500, 1000, 2000, 4000, 8000）
lift2.exe set-polling 8000

# 修改静默高度（1 为 1mm，2 为 2mm）
lift2.exe set-lod 1

# 硬件级重置 USB 端口
lift2.exe reset-usb

# 写入注册表防休眠补丁
lift2.exe fix-power
```
